# Final Fantasy 15 Food Catalog
Aktuell gibt es keine vernünftige Auflistung von den ganzen Gerichten und Zutaten aus Final Fantasy 15. Die Vielfalt ist jedoch gross und die Gerichte so detailreich und hübsch, dass sie irgendwo einfach dargestellt werden müssen. 

Aufgebaut ist das Projekt mit Vue und Typescript.

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```
